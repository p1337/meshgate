Meshtastic remote access gateway

◇ MESHGATE

Flash an ESP32 bridge that turns a Bluetooth-only Meshtastic radio into a local or Tailscale-reachable TCP node.

Zero-install WebSerial flasher

Existing MeshGate? Use Check & Install Latest Release on the device control page for normal updates. It preserves Wi-Fi, BLE, VPN, MQTT and OTA configuration.
USB is for factory installation or recovery: leave Erase device unchecked when preserving an existing configuration. Enabling erase permanently deletes every saved Wi-Fi password, BLE pairing, VPN key and MQTT setting.
Do not disconnect early: wait for Installation complete, then select Next to release the serial connection and start MeshGate. The installer waits another 30 seconds for startup. The Nano RGB LED must then turn off; if it remains purple, press RST once. Do not hold B1.

Update without USB

Open the MeshGate control page at its LAN or Tailscale IP and press Check & Install Latest Release. MeshGate downloads the official GitHub release, verifies SHA-256, installs it and reboots automatically.
